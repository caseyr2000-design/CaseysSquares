# Casey's Squares

Football squares pool board, hosted on GitHub Pages.

- `index.html`, `app.js`: the board.
- `config.js`: the address of the Google Apps Script that stores squares, invitations and payments. Edit it here (pencil icon) if you redeploy the script as a new web app.

Squares data isn't stored in this repository.

`apps-script/` holds a copy of the Google Apps Script source (Code.gs and Index.html) that runs in the owner's Google account. It contains no passwords.
